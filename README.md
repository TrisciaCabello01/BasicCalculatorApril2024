# Basic Calculator

A simple **Basic Calculator** desktop application created using **Visual Basic .NET (VB.NET)** as part of a class activity.

## 📌 About the Project

**Basic Calculator** is a beginner-friendly calculator application developed in **April 2024**. The project was created as one of our classroom activities to practice the fundamentals of Visual Basic .NET and Windows Forms application development.

The application provides a simple interface for performing basic mathematical calculations and demonstrates how user input, buttons, and calculation logic can be connected together in a desktop application.

## 🛠️ Built With

* **Visual Basic .NET (VB.NET)**
* **Windows Forms**
* **Visual Studio**

## ✨ Features

* Basic arithmetic calculations
* Simple and easy-to-use interface
* Button-based user input
* Designed as a beginner-level desktop application
* Created as part of a programming class activity

This project was created to gain practical experience with **VB.NET programming** and to understand the basic concepts involved in developing a graphical user interface (GUI) application.

To run the project:

1. Clone or download this repository.
2. Open the project using **Visual Studio**.

4. Build the project.
